

# 🛡️ Cybersecurity Internship Projects

This repository contains cybersecurity internship tasks completed using Kali Linux and penetration testing tools.  
The projects demonstrate practical skills in network security, vulnerability assessment, and web application security testing.

---

## 📌 Completed Tasks

### 🔍 Task 4 - Research Report on Common Network Security Threats
- Denial of Service (DoS / DDoS) Attacks
- Man-in-the-Middle (MITM) Attacks
- Spoofing Attacks (IP / ARP / DNS)
- Security risks in real-world networks
- Prevention and mitigation techniques

---

### 🛡️ Task 7 - Vulnerability Scanning with Nikto
Tool Used: Nikto Web Vulnerability Scanner

- Web server vulnerability scanning
- Detection of outdated Apache and PHP versions
- Identification of missing security headers
- Discovery of exposed files and directories
- Security misconfiguration analysis

---

### 💉 Task 9 - SQL Injection Exploitation
Environment: DVWA (Damn Vulnerable Web Application)

- SQL Injection testing on login and input fields
- Manual payload injection techniques
- Authentication bypass demonstration
- Identification of insecure SQL queries
- Mitigation using prepared statements and input validation

---

### 🌐 Task 10 - Network Security Assessment
Tools Used:
- Nmap (Network Scanning)
- Wireshark (Packet Analysis)

Activities:
- Network host discovery
- Port scanning and service detection
- Packet capture and traffic analysis
- Vulnerability identification in network services
- Security assessment reporting
